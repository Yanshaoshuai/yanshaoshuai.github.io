# 前端开发

前端开发涉及 HTML、CSS 和 JavaScript。

## HTML 基础

```html
<!DOCTYPE html>
<html>
<head>
    <title>我的页面</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>这是我的第一个网页</p>
</body>
</html>
```

## CSS 样式

```css
body {
    font-family: Arial, sans-serif;
    background: #f5f5f5;
}

.container {
    max-width: 1200px;
    margin: 0 auto;
}
```

## JavaScript 基础

```javascript
// 变量声明
const name = 'JavaScript';
let count = 0;

// 函数
function greet(name) {
    return `Hello, ${name}!`;
}

// 箭头函数
const add = (a, b) => a + b;
```
