# 全排列
给定一个不含重复数字的数组 nums ，返回其 所有可能的全排列 。你可以 按任意顺序 返回答案。
```java
class Solution {
    public List<List<Integer>> permute(int[] nums) {
        List<Integer> output = new ArrayList<>();
        for (int num : nums) {
            output.add(num);
        }
        List<List<Integer>> result = new ArrayList<>();
        backTrack(output, result, 0, nums.length);
        return result;
    }

    /**
     * 固定[0,current-1] 从 [current,n-1]选取当前位置的数 每次选取的路径都是一个结果
     * 如果current=n说明当前结果已经出来了 回溯上一步继续检测下一个可能的结果
     */
    void backTrack(List<Integer> output, List<List<Integer>> result, int cur, int n) {
        if (cur == n) {
            result.add(new ArrayList<>(output));
        }
        //i=cur 包括cur在当前位置的结果
        for (int i = cur; i < n; i++) {
            Collections.swap(output, cur, i);
            backTrack(output, result, cur + 1, n);
            Collections.swap(output, cur, i);
        }
    }
}
```

时间复杂度: 时间复杂度为 O(n×n!)
