# 二分搜索

二分搜索用于在有序数组中快速找到对应值

-  如果l<=r,将数组均分为[l,mid-1]和[mid+1,r],
- 如果nums[mid]==target,则找到了,直接返回
- 如果nums[mid]< target,说明在[mid+1,r]中,继续在[mid+1,r]重复上述步骤搜索
- 如果nums[mid]> target,说明在[l,mid-1]中,继续在[l,mid-1]重复上述步骤搜索
- 如果l>r说明没有找到,直接退出

```java
class Solution {
   public int search(int[] nums, int target) {
        int l=0;
        int r=nums.length-1;

        while(l<=r){
            int mid=(l+r)/2;
            if(nums[mid]==target){
                return mid;
            }else if(nums[mid]<target){
                l=mid+1;
            }else {
                r=mid-1;
            }
        }

        return -1;
    }
}
```

# 搜索有序数组旋转后的数组

整数数组 nums 按升序排列，数组中的值 互不相同 。

在传递给函数之前，nums 在预先未知的某个下标 k（0 <= k < nums.length）上进行了 向左旋转，使数组变为 [nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]（下标 从 0 开始 计数）。例如， [0,1,2,4,5,6,7] 下标 3 上向左旋转后可能变为 [4,5,6,7,0,1,2] 。

给你 旋转后 的数组 nums 和一个整数 target ，如果 nums 中存在这个目标值 target ，则返回它的下标，否则返回 -1 。

你必须设计一个时间复杂度为 O(log n) 的算法解决此问题。

示例 1：

输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4

## 思路

- 数组满足以下规律
    - 左侧区间单调递增
    - 右侧区间单调递增
    - 左侧所有值都大于右侧所有值 => nums[0]>nums[n-1]

- 利用二分搜索求解,mid=(l+r)/2,如果nums[mid]=target直接返回,否则需要考虑确定下一步要搜索的区间,即l和r的值
    - 如果mid在左侧区间  => 需满足nums[mid]>=nums[0]
        - 此时nums[l,mid]单调递增,如果target在此区间的话将r设为mid-1
        - 否则将l设为mid+1
    - 如果mid在右侧区间 => 需满足nums[mid]< nums[0]
        -  此时nums[mid,r]单调递增,如果target在此区间的话,将l设置为mid+1
        -  否则将r设置为mid-1
    - 如果l>r说明没找到返回-1

```java
class Solution {

    public int search(int[] nums, int target) {
        int l=0;
        int r=nums.length-1;
        while(l<=r){
            int mid=(l+r)/2;
            if(nums[mid]==target){
                return mid;
            }

            if(nums[mid]>=nums[0]){
                if(nums[l]<=target&&target<=nums[mid]){
                    r=mid-1;
                }else{
                    l=mid+1;
                }
            }else {
                if(nums[mid]<=target&&target<=nums[r]){
                    l=mid+1;
                }else{
                    r=mid-1;
                }
            }
        }

        return -1;
    }
}
```
