# Java 基础

Java 是一门广泛使用的面向对象编程语言。

## Hello World

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

## 主要特性

- 跨平台（Write Once, Run Anywhere）
- 自动内存管理（垃圾回收）
- 丰富的类库生态
- 强类型语言
