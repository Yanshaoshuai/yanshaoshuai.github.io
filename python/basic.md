# Python 基础

Python 是一门简洁优雅的编程语言。

## Hello World

```python
print("Hello, Python!")
```

## 主要特性

- 语法简洁，易于学习
- 丰富的第三方库
- 跨平台
- 多范式支持（面向对象、函数式）

## 常用库

```python
# 数据处理
import pandas as pd
import numpy as np

# Web 开发
import flask
import django

# 机器学习
import sklearn
import tensorflow
```

## 虚拟环境

```bash
# 创建虚拟环境
python -m venv venv

# 激活
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```
